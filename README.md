# Mini-Fighter（小人格斗）

浏览器端 2D 横版格斗小游戏，纯 HTML5 Canvas，无需构建或安装依赖。可选 **武者** / **弓手**，支持木桩练习、人机对打与三关闯关。

**在线仓库：** [github.com/Alex-Lee-morning/Mini-Fighter](https://github.com/Alex-Lee-morning/Mini-Fighter)

## 快速开始

1. 克隆或下载本仓库  
2. 用浏览器直接打开 `index.html`（建议 Chrome / Firefox / Safari）  
3. 在菜单中选择模式、角色、场景与血量，点击 **开始**

> 若通过 `file://` 打开遇异常，可用本地静态服务，例如：  
> `python3 -m http.server 8080`  
> 然后访问 `http://localhost:8080`

## 游戏模式

| 模式 | 说明 |
|------|------|
| **木桩练习** | 对手不扣血，统计总伤害与最高连击，适合练连招 |
| **人机对打** | 与 AI 对战，可选简单 / 普通 / 困难 |
| **闯关（3 关）** | 逐关变强的敌人，共 3 波 |

## 角色

### 武者（近战）

- 四连普攻、下段 / 扫踢、升龙与空中下劈  
- **U**：聚气推弹（红色尖波）  
- **W + A/D + U**：斜上短光柱  
- **按住 S 蓄力 U**：裂地斩（土黄色地面尖刺）  
- **空中 S + A/D + J**：俯冲至最底层（短 CD）  
- **空中 S + J**：坠踢（短 CD）  
- **地面 S + J**：贯落（穿台直落底层）

### 弓手（远程）

- 站射四连（前两段弱箭、后两段强化箭）；贴近时切换为低伤近战  
- **U**：抡弓横扫（低伤、强击退、长后摇）  
- **W + A/D + U**：扇形三连箭  
- **按住 S 蓄力 U**：三支平射  
- **空中 S + A/D + J**：斜下约 45° 蓝色激光箭并腾空（短 CD）  
- **空中 S + J**：向下散射并腾空（短 CD）  
- 闪避距离较武者更远

## 操作一览

| 按键 | 功能 |
|------|------|
| **A / D** | 左右移动 |
| **K** | 跳跃（空中可二段跳） |
| **S** | 格挡（地面） |
| **S + A/D** | 蹲移 |
| **J** | 普攻 / 派生（见角色说明） |
| **L** | 闪避 |
| **U** | 角色特技（见上） |
| **W** | 上段架势（配合 J / U） |
| **S + K**（上层台面） | 下落穿板 |
| **S + K**（地面蹲姿） | 蹲跳踢 |
| **Esc / P** | 暂停；Esc 或「继续游戏」恢复 |

## 项目结构

```
mini-fighter/
├── index.html      # 页面、菜单与 HUD
├── style.css       # 界面样式
├── game-data.js    # 地图、招式表、弓手数值与共用工具
├── game-render.js  # 角色绘制、受击框与攻击框
├── game-main.js    # 输入、物理、AI、碰撞与主循环
└── README.md
```

## 技术说明

- 无框架、无打包：三个脚本按 `game-data.js` → `game-render.js` → `game-main.js` 顺序加载  
- 画布逻辑分辨率 **900×480**，世界宽度约 **3200**，带镜头跟随与缩放  
- 受击框与像素小人外廓对齐（约 72×108）
